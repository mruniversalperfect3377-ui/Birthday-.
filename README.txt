# Birthday Website — For My Cutie Jii 💜

## Put your files here
- assets/favourite.jpg  -> the favourite photo
- assets/photo2.jpg     -> photo 2
- assets/photo3.jpg     -> photo 3
- assets/photo4.jpg     -> photo 4
- assets/song.mp3       -> your birthday song/audio

## Run
Open `index.html` in a browser. Internet is used only for the Google Fonts; the photos/audio are local.

## Next customization
The text, photos, exact animation timing, and song placement can be tuned after you provide the actual files.
